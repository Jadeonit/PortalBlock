# PortalBlock

Paper-плагин для 1.21.11: не даёт игрокам войти в портал Нижнего мира.

Когда игрок подходит к порталу, его останавливает на краю — фиолетовый экран
и телепорт не появляются. В чат приходит сообщение от первого лица:
«Что-то изнутри не пускает тебя туда...».

## Сборка

```bash
mvn package
```

Готовый файл: `target/PortalBlock.jar` — положить в папку `plugins` сервера.

## Настройка

`plugins/PortalBlock/config.yml`:

```yaml
enabled: true
message: "&5&oЧто-то изнутри не пускает тебя туда..."
message-cooldown-seconds: 5
block-movement: true
push-out: true
```

- `message` — сообщение при попытке входа (`&` — цветовые коды, пусто — отключить).
- `message-cooldown-seconds` — чтобы сообщение не спамилось, пока игрок стоит у портала.
- `block-movement` — не пускать игрока в блок портала (убирает фиолетовый оверлей).
- `push-out` — если игрок всё же оказался внутри портала (вход в игру, телепорт плагином),
  выталкивать его на ближайший безопасный блок.

## Права

- `portalblock.bypass` — разрешает пользоваться порталами (по умолчанию у операторов).
- `portalblock.admin` — доступ к `/portalblock reload`.

## Команды

- `/portalblock reload` (алиас `/pblock reload`) — перечитать конфиг.
